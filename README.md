# TY Introduction to Coding with Python

This repository is designed to introduce Transition Year students to the basics of coding using Python. It contains a structured set of lessons to be covered in class over an 8-week period, as well as additional follow-on lessons and exercises for students to attempt independently. Each lesson includes exercises, solutions, and teaching resources to support both classroom learning and self-study.
