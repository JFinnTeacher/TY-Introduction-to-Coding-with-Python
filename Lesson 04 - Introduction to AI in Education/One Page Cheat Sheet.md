# One-page cheat sheet 

Best quick sources:

- - Britannica, National Archives, WHO, NHS, NIH, EU, Library of Congress, Google Scholar
- Quick checks:
  - site:domain query; click-through verification; look for dates and authors; archive dead links via web.archive.org
- Strong prompt checklist:
  - Audience, length, format
  - Number of bullets/claims
  - Examples/misconceptions/timeframe
  - Source request: titles, authors, dates, working links
- Red flags:
  - No sources; broken links; precise stats without references; misattributed quotes; conflating concepts
- Phrases to use:
  - “List uncertainties in your answer.”
  - “Cite sources with working links and explain how they support each claim.”
  - “Limit to 3–5 bullets, ≤120 words, UK context if possible.”

Optional extensions (if time allows or for homework)

- Compare two AI tools’ answers to the same question; evaluate which is better evidenced (rubric: author/date/domain/evidence quality).
- Build a credibility rubric with 4 criteria and apply it to two sources.
- Students create a “hallucination bingo” card from today’s red flags and try to spot one next week.
